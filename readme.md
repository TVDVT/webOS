# WebOS
A personal WebOs presenting me!

## Features
- A top-bar with a live clock and a healthbar
- Draggable windows
- Closable windows

## Applications

### TrueNotes
A personnal app where I put thoughts about true crime stories I enjoyed :D
The design is centered around Undertale's field of flowers, with each footstep being a story; I wanted to make it more original than the side bar I had in WebOS 1.

### To do app

### Countdown app
A simple countdown app where you can set countdowns and a new window appears for each countdown. They are editable and deleteable :D
You can also change the precision shown on each windows (in case seeing seconds stresses you out)

### Skeletale
An undertale - anatomy based "autobiography" of me, it's part of my WebOs 1 and I haven't really updated it since.
