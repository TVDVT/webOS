# WebOS
An Undertale themed WebOs presenting me, with some other functionalities!
This is my very first HTML project (after WebOS 1!)

## Features
- A top-bar with a live clock and a healthbar
- Draggable windows
- Closable windows

## Applications

### TrueNotes (personal)
A personnal app where I put thoughts about true crime stories I enjoyed :D
The design is centered around Undertale's field of flowers, with each footstep being a story; I wanted to make it more original than the side bar I had in WebOS 1.

## AI usage declaration
This WebOS is the first HTML project I undertook, and even with the help of guides, I had very dumb bugs. I used AI for:
- Understanding CSS, JavaScript and html  (especially for text imputs)commands
- Debugging
- Layout and math behind the countdown app

I prioritized using real websites like W3schools, but when I was very unmotivated and in a rush I just asked AI to tell me how to use some features.
